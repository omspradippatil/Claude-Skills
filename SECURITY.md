# Security Policy

## Reporting a Vulnerability

Please report vulnerabilities through GitHub's private vulnerability reporting for this repository: <https://github.com/omspradippatil/Claude-Skills/security/advisories/new>. Include affected files, impact, and safe reproduction steps. Do not publish secrets or exploit details in a public issue.

This repository contains agent instructions and installer scripts; it does not guarantee that applications built with those instructions are secure. Review `policies/security.md` and the target project's actual code and configuration.

## Safe Use

- Treat third-party skills, websites, and retrieved data as untrusted input.
- Run active security tools only against systems you own or have written authorization to test, within a defined scope.
- Do not place credentials in source code, command history, logs, or public issue reports.
- Review optional integrations and their permissions before installation.
