Give each coding task the instructions it needs.

Claude-Skills is a maintained set of engineering policies and task-specific skills for coding agents. It routes work to relevant guidance instead of loading every skill into every task.

Read the setup guide See the router

Instruction adapters are included for Claude Code, Antigravity, Codex, and Cursor. Native skill discovery varies by product and version.

How routing works

One source. A small task-specific context.

The root router points agents to shared policies and the selected skill files. The registry supplies activation cues. The agent reads each chosen skill in full before using it.

  1. Read the core policyStart every task with `policies/core.md`.
  2. Choose relevant guidanceMatch task intent to policies and skills in `skills-lock.json`.
  3. Read selected filesLoad each selected `SKILL.md` and any required references.
  4. Verify the resultRun relevant checks and report what remains unverified.

Canonical policies

Practical engineering rules

Policies cover cross-cutting requirements. Skills add focused domain guidance only when the task needs it.

  • Core routing and evidence
  • Simple, scoped engineering
  • Security and threat boundaries
  • SEO and indexing
  • UI quality and accessibility
  • Production release checks

Install

Start with the minimal profile

Install in a target project. Existing files are preserved unless you pass `--force`. Optional third-party tools are never installed by the base command.

bash install.sh --target project --minimal

# Select exact skills
bash install.sh --target project --platform agents --skills ui-ux-pro-max,security-auditor,seo-marketing
