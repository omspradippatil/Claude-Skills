How Progressive Disclosure Works

Skills do not dump thousands of lines into your context window at start. They load gracefully in 4 distinct lifecycle stages.

STAGE 01

Lightweight Indexing

At agent startup, only skill headers (~20 tokens each) are indexed. Token impact is virtually zero.

tokens: ~24 tokens
STAGE 02

Context Activation

When you mention a design or database task, the agent injects the full `SKILL.md` rules on-demand.

Local Execution

Scripts (Archify, Playwright, SEO scrapers) execute locally on your machine with verifiable output.

STAGE 04

Got Questions?

Frequently Asked Questions

Are the installed skills completely free?

Yes, 100%. We removed any dependencies on paid proprietary plugins. All memory persistence, architecture visualizers, heuristics, and testing skills run locally on your hardware with zero subscriptions or API fees.

Will these skills slow down my AI coding assistant?

No. Thanks to the Progressive Disclosure system, only ~20 tokens per skill are registered on agent boot. Full heuristics and instructions are only injected when a matching user prompt triggers that specific skill.

What is the difference between Global and Project Scope?

Global installation places skills in `~/.agents/skills` and `~/.claude/skills` so they are available across every project on your computer. Project scope installs skills inside your current directory (`./.claude/skills` and `./.agent/skills`), ideal for team repositories and project-isolated workflows.

How do I completely uninstall all skills?

Simply run `./install.sh --uninstall` or use the quick uninstaller: `bash -c "$(curl -fsSL https://raw.githubusercontent.com/omspradippatil/Claude-Skills/main/uninstall.sh)"`. It cleanly removes all symlinks, CLIs, and cloned repositories.
